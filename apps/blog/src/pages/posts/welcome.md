# Welcome to Minions Bundle: Agency

We're excited to introduce **Minions Bundle: Agency** — Full-stack IT agency bundle — prospecting, outreach, CRM pipeline, delivery, billing, and client management for productized service businesses.

## What's Included

- **TypeScript SDK**: `npm install @minions-bundles-agency/sdk`
- **Python SDK**: `pip install minions-bundles-agency`
- **CLI**: `npm install -g @minions-bundles-agency/cli`
