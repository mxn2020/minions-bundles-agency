# Minions Bundle: Agency

Full-stack IT agency bundle — prospecting, outreach, CRM pipeline, delivery, billing, and client management for productized service businesses

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-bundles-agency/sdk`) — Core library for Node.js
- **Python SDK** (`minions-bundles-agency`) — Python bindings
- **CLI Tool** (`@minions-bundles-agency/cli`) — Command-line interface
- **Web App** — Interactive playground at [app.minions.wtf](https://app.minions.wtf)
